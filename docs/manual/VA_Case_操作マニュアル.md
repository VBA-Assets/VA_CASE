# 第1章 ツールの概要

## 1.1 VA Caseシリーズとは

VA Caseシリーズは、小規模な法律事務所が、事件の情報・保管するファイル・領収書など・電話の記録を、事務所の共有フォルダだけで、何人かで共有・管理するためのツールです。共有フォルダには、ふつうのネットワークのフォルダのほか、SharePoint・OneDrive の同期フォルダも使えます。

次の4つのツールがあります。4つは別々のプログラム（実行ファイル）で、要るものだけを使えます。

| ツール | 実行ファイル | できること |
|---|---|---|
| VA Case | `VA_Case.exe` | 事件の情報（依頼者・相手方・裁判所・担当など）を管理します。事件メモ・期日請書・送付書の PDF を作ります。終了した事件のデータフォルダを ZIP にまとめます |
| VA Filing | `VA_Filing.exe` | スキャンや受信した FAX などのファイルに名前を付けて、事件のフォルダへ保管します。担当者へのショートカットや写しも作ります |
| VA Receipt | `VA_Receipt.exe` | 領収書などのファイルに、日付・相手先・金額の名前を付けて、種別ごとのフォルダへ保管します |
| VA Call | `VA_Call.exe` | 電話のメモを記録し、宛先の所員にメールで知らせます |

VA Filing は、VA Case の事件の一覧を読んで、保管先の事件を選べます（読むだけで、VA Case のデータは書き換えません）。VA Case を使わずに、VA Filing だけを使うこともできます。

## 1.2 できること・できないこと

**できること**

- 事務所の共有フォルダに置いた1つのファイル（共有データ）を、何人かで見て、直す
- 何人が同時に開いても、データを壊さない（直せるのは1人ずつです。1.3）
- 一覧の検索・フィルタ、Excel への貼り付け（コピー）、CSV での出力と取り込み
- 毎日のバックアップ
- 暗号化した仮想ドライブ（Cryptomator など）の中の共有フォルダでも使う（第8章）

**できないこと（していないこと）**

- インターネットにつながること。どのツールも外部と通信しません（更新の確認や、利用状況・エラーの送信もしません）。VA Call のメールは、パソコンのメールソフトを開くだけで、送信は利用者がメールソフトで行います
- サーバーやクラウドのサービスを使うこと。データのやり取りは、共有フォルダのファイルだけで行います
- 1つのツールを、2人以上で同時に直すこと。編集モードにできるのは、ツールごとに1人だけで、ほかの人は閲覧だけになります（VA Case を誰かが直している間も、VA Call は別の人が直せます）
- Excel の .xlsm から直接データを読むこと。Excel 版のデータは、CSV に保存してから取り込みます（2.8）
- データの暗号化。共有データを暗号化したいときは、暗号化した仮想ドライブなどを使ってください（第8章）

## 1.3 安全の考え方

VA Caseシリーズは、次の考え方で作っています。

**データを壊さない**

- 共有データは、ツールごとに1つのファイル（`VA_Case.json`・`VA_Filing.json`・`VA_Receipt.json`・`VA_Call.json`）です。書き込むときは、同じフォルダに一時のファイルを書いてから置き換えます。書き込みの途中で PC が止まっても、共有データが半分だけ書かれることはありません。
- 書き込む直前に共有データを読み直し、読み込んだ後にほかの人が書き換えていないかを確かめます。書き換えられていれば、書き込まずに止めて知らせます。
- 書き込んだ後に読み直し、書いたとおりになっているかを確かめます。
- 同期のソフトが作った「競合の写し」を見つけたら、黙って使わずに知らせます（10.1）。

**編集は1人ずつ**

［編集を始める］を押すと、共有データと同じフォルダに「編集中」の印（ロックファイル）を置きます。印がある間、ほかの人はそのツールを閲覧だけで使います。

**安全に関わる機能は、切り替えられないようにする**

安全に関わる機能・設定は、安全な側に決めておき、切り替えて使う余地を残していません。切り替えられるようにすると、誤って切り替える危険が必ず生まれるためです。

- 例：終了した事件のデータを保管庫（ふだん開かない置き場所）へ移すことは、VA Case の機能に入れていません。VA Case は、日常の共有フォルダの中の「移送待ち」に ZIP を置くまでを行い、保管庫へは、利用者が保管庫を開いたときに移します（8.4）。「VA Case から直接保管庫へ移す」設定も設けていません。
- 例：保管先などの基点のフォルダが見つからないときは、新しく作らずに止まります（8.2）。

**事件の情報を、利用者の PC に残さない**

共有データは、起動のたびに共有フォルダから読み込み、PC の中には写しを残しません。PC をなくしたときや、乗っ取られたときに、事件の情報が PC に残らないようにするためです。共有フォルダに届かないときは、閲覧もできません。

## 1.4 どの情報がどこに置かれるか

事務所の情報の取扱方法を定めるときに、そのまま引けるようにまとめました。

| 情報 | 置き場所 |
|---|---|
| 事件の情報・保管の記録・領収書等の記録・電話メモ（共有データ） | 事務所の共有フォルダの `VA_Case.json`・`VA_Filing.json`・`VA_Receipt.json`・`VA_Call.json`。事務所の設定（選択肢・フォルダ規則・所員など）も、この中に入ります |
| 「編集中」の印（ロックファイル） | 共有データと同じフォルダの `VA_Case.json.<人>@<PC>.lock` など。編集している人の名前と PC の名前が入ります |
| 日次バックアップ | 各ツールの「この PC の設定」で決めたバックアップのフォルダの `yyyymmdd_VA_Case.json` など（3.9） |
| この PC の設定 | この PC の `%APPDATA%\VA Case\case.json`・`filing.json`・`receipt.json`・`call.json`。共有データ・バックアップなどの場所、ウィンドウの大きさ、列の幅だけで、事件の情報は書きません |
| 誤りの記録（診断情報に使う） | この PC の `%APPDATA%\VA Case\case_errors.json` など。誤りの種類と、プログラムの中の場所だけを書き、氏名などの値やファイルの場所は書きません（3.10） |
| 事件メモ・期日請書・送付書の PDF | その事件のデータフォルダ（第4章） |
| 終了した事件のデータフォルダの ZIP | 移送待ちのフォルダ。保管庫へは、利用者が移します（4.8・8.4） |
| VA Filing・VA Receipt で保管したファイル | 保管フォルダ。ショートカット・写しは、事務所の設定で決めたフォルダ（第5章・第6章） |
| CSV に出力したファイル | 利用者が選んだ場所。氏名・住所などがそのまま入っています。使い終わったら消すなど、置き場所に気をつけてください |

# 第2章 導入方法

## 2.1 配布物の構成

4つのツールは、「VA Caseシリーズ（統合版）」のインストーラーに入っています。インストールの途中で、入れるツールを選べます。インストールすると、次のものが入ります。

| ファイル | 内容 |
|---|---|
| `VA_Case.exe`・`VA_Filing.exe`・`VA_Receipt.exe`・`VA_Call.exe` | 各ツールの本体（選んだものだけ。Python などを別に入れる必要はありません） |
| マニュアル（フォルダ） | このマニュアル（PDF） |
| `はじめにお読みください.txt` | 収録しているツールと、データの置き場所の案内 |
| `README.md` | ツールの概要 |
| `LICENSE.txt` | ライセンス（MIT License） |
| `THIRD_PARTY_NOTICES.txt` | ツールが使っている部品のライセンスの表示 |

ソースコードは、GitHub で公開しています（第12章）。

## 2.2 起動方法

1. スタートメニュー（またはデスクトップ）の「VA Case」「VA Filing」「VA Receipt」「VA Call」を押します。
2. 画面が出るまで、少し時間がかかることがあります（1つのファイルにまとめた実行ファイルを、起動のたびに展開するためです）。

Windows の SmartScreen などが警告を出すことがあります。電子署名のない実行ファイルに出る、一般的な警告です。気になる場合は、公開しているソースコードを確かめるか、ご自身でビルドしてお使いください。

初めて起動したときは、共有データの場所を尋ねます（2.6）。

## 2.3 動作環境

- Windows 10・11（64bit）
- インターネットへの接続は要りません
- VA Filing・VA Receipt のプレビューの字の読み取り（5.8）には、Windows の日本語の文字認識を使います（日本語版の Windows には、初めから入っています）

配布している実行ファイル（exe）は、Windows 用です。Mac では、公開しているソースから動かせます（動作は保証しません）。Python 3（Tk の入ったもの）を入れ、ソースのフォルダで `python3 -m pip install -r requirements.txt` を実行して部品を入れてから、`python3 main_case.py`（VA Filing は `main_filing.py`、VA Receipt は `main_receipt.py`、VA Call は `main_call.py`）で起動します。Mac では、次の点が Windows と違います。

- この PC の設定は、ホームの `.va_case` フォルダに置きます。
- VA Filing のショートカットは作りません（写しは作ります）。
- プレビューの画像の字の読み取りは使えません。
- VA Filing・VA Receipt の［消す］は、ファイルをホームの `.Trash`（ゴミ箱）へ移します。

## 2.4 この PC の設定ファイルと、アンインストール

- この PC の設定は、`%APPDATA%\VA Case` のフォルダに、ツールごとに1つのファイル（`case.json`・`filing.json`・`receipt.json`・`call.json`）で覚えます。書くのは、共有データ・バックアップなどの場所、ウィンドウの位置と大きさと最大化していたか、一覧の列の幅、事務所の設定の画面の大きさ、プレビューを出すかとその幅です。事件の情報は書きません。
- 不具合の相談に使うため、起きた誤りの種類と、プログラムの中の場所を、同じフォルダの `<ツール>_errors.json`（`case_errors.json` など）に、新しいものから 30 件覚えます（3.10）。
- アンインストールするときは、Windows の［設定］の［アプリ］から「VA Caseシリーズ（統合版）」を選びます。この PC の設定と誤りの記録も消すかを尋ねます（「いいえ」を選ぶと残り、入れ直したときに引き継げます）。
- 共有フォルダの共有データ・保管したファイル・バックアップは、アンインストールしても消えません。

## 2.5 共有フォルダを用意する

はじめに、事務所の共有フォルダに、共有データを置くフォルダを決めます。

- 事務所の人がみな、読み書きできるフォルダにします（ネットワークのフォルダ、SharePoint・OneDrive の同期フォルダ、暗号化した仮想ドライブの中のフォルダなど）。
- 4つのツールの共有データ（`VA_Case.json` など）は、同じフォルダに置いても、別のフォルダに置いてもかまいません。同じフォルダに置いても、「編集中」の印はツールごとに分かれます。
- 次のフォルダも用意しておきます（使うツールの分だけ）。ツールはこれらのフォルダを作らないので、先に作っておいてください（8.2）。

| フォルダ | 使うツール | 用途 |
|---|---|---|
| バックアップのフォルダ | 4つとも | 日次バックアップを置く（3.9） |
| 事件のデータフォルダ | VA Case・VA Filing | 事件ごとの書類を置くフォルダ |
| 移送待ちのフォルダ | VA Case | 終了した事件の ZIP を置く（日常の共有フォルダの中。4.8） |
| 読込フォルダ | VA Filing・VA Receipt | スキャンの保存先など、保管する前のファイルが入るフォルダ |
| 保管フォルダ・写しの置き場所 | VA Filing・VA Receipt | 保管したファイル、ショートカット・写しを置くフォルダ |

## 2.6 各ツールの「この PC の設定」

初めて起動すると、「はじめに、共有データのファイル（VA_Case.json）の場所を設定してください。」と出て、「この PC の設定」の画面が開きます。後から直すときは、メニューの［ファイル］→［この PC の設定…］で開きます。この設定は PC ごと（Windows のユーザーごと）です。事務所の人は、それぞれの PC で設定します。

**共有データを新しく作るとき（事務所で最初の1人）**

1. 「共有データのファイル」の欄に、共有データを置くフォルダの場所を入れて（貼り付けて）、［OK］を押します。
2. 「共有データのファイルがありません。新しく作りますか？」と尋ねるので、［はい］を押します。そのフォルダに `VA_Case.json` などができます。

ほかの人がすでに作っているときは、作らずに、同期が終わるのを待ってください（同期フォルダでは、ほかの PC で作ったファイルが届くまでに時間がかかることがあります）。

**すでにある共有データを使うとき（2人目から）**

「共有データのファイル」の［参照…］を押し、共有フォルダの `VA_Case.json` などを選びます。事務所の人がみな、同じファイルを指すようにします。

**設定の欄**

| 欄 | ツール | 内容 |
|---|---|---|
| 共有データのファイル | 4つとも | 共有フォルダの `VA_Case.json` など |
| バックアップのフォルダ | 4つとも | その日の最初に読み込んだときに、共有データの写しを置くフォルダ。空ならバックアップしません |
| 事務所のフォルダの場所 | VA Case・VA Filing・VA Receipt | 事務所で共有しているフォルダ（事件のフォルダ・スキャンのフォルダなどをまとめて置いているフォルダ）が、この PC で見える場所 |
| 移送待ちの場所 | VA Case | 終了した事件の ZIP を置くフォルダ（日常の共有フォルダの中） |
| 終了処理の ZIP を圧縮する | VA Case | 印を付けると、ZIP を圧縮します。既定は無圧縮です（スキャンした PDF などは、ほとんど縮まないため） |
| VA Case の共有データ | VA Filing | VA Case の `VA_Case.json`。事件呼名・データフォルダ・担当区分を読みます（読むだけで、書き込みません）。VA Case を使わない場合は、空のままにします |

**事務所のフォルダの場所について**

PC によって共有フォルダの場所が違う事務所（OneDrive・SharePoint の同期フォルダは、利用者ごとのフォルダの下にできます。Mac でも使う場合も）では、この欄を入れておきます。入れておくと、その中のフォルダ（データフォルダ・保管フォルダ・読込フォルダなど）を、ここからの相対で記録します。そのため、PC ごとに場所が違っても、同じデータを使えます。どの PC でも同じ場所（同じドライブ名）なら、空でかまいません。

- 事務所の人は、みな、それぞれの PC で、この欄を入れておきます。
- 入れていない PC で、ほかの PC が相対で書いたフォルダを開こうとすると、「この PC の場所として読めません（事務所のフォルダの場所を設定してください）」と出ます。

## 2.7 事務所の設定

選択肢・フォルダ規則・所員などの「事務所の設定」は、共有データの中に入り、事務所でみなが同じものを使います。メニューの［ファイル］→［事務所の設定…］で開きます（ツールによって名前が少し違います）。

- 閲覧モードでは、見るだけです。直すときは、本体の［編集を始める］を押します（画面を開いたままでも押せます。押すと、直せる形で開き直します）。
- 直したら［OK（書き込む）］を押します。
- 表の形の設定は、［足す］［直す］［消す］［上へ］［下へ］で直します（行をダブルクリックしても直せます）。

各ツールの事務所の設定は、次のとおりです。

| ツール | タブ | 内容 |
|---|---|---|
| VA Case | 選択肢 | 現況区分・受任区分・事件区分・担当区分・依頼人立場の選択肢と、担当区分の詳細（担当の弁護士の氏名。4.6） |
| VA Case | フォルダ規則 | 終了した事件の ZIP を置く場所（4.8） |
| VA Case | 事務所 | 事務所の電話番号・FAX 番号（送付書に書きます） |
| VA Case | 裁判所 | 裁判所ごとの電話番号・FAX 番号（事件メモと送付書に使います） |
| VA Filing | 保管先 | 事件呼名ごとに覚えた保管先（5.5） |
| VA Filing | 読込フォルダ | 保管するファイルを読み込むフォルダ（5.2） |
| VA Filing | 複製作成先 | 担当区分ごとに、ショートカットか写しを置くフォルダ（5.6） |
| VA Filing | 特別な写し | 内容にある語が入っているときに、写しを置くフォルダ（5.6） |
| VA Filing | そのほか | 読み込まないファイル名の先頭、保管フォルダを選ぶときの初めのフォルダ |
| VA Receipt | 種別と保管フォルダ | 種別ごとの保管フォルダ（6.2） |
| VA Receipt | 読込フォルダ | 保管するファイルを読み込むフォルダ |
| VA Receipt | そのほか | 枝番の付け方、ファイル名が日付で始まらないときの日時、読み込まないファイル名の先頭（6.3・6.4） |
| VA Call | 所員 | 所員名・メールアドレス・ユーザー名（Windows）（7.2・7.5） |
| VA Call | 選択肢 | 用件・対応・処理の選択肢 |

新しく作った共有データには、次の選択肢が初めから入っています。事務所に合わせて直してください。

- VA Case：現況区分（A:未了・B:精算管理・C:終了・D:相談のみ・E:相談不可）、受任区分（A:事務所）、事件区分（A:管財・B:個人一般・C:個人債務・D:企業・E:顧問）、依頼人立場（原告・被告・申立人・相手方など）。担当区分は、事務所ごとに入れます。
- VA Filing：特別な写しの語（職務上請求・弁護士会照会。置き場所は空なので、写しは作りません）
- VA Receipt：種別（領収書・請求書・支払明細書・納品書・出金伝票・売上票・報酬明細書・振込通知書・給与明細書。保管フォルダは空です）
- VA Call：用件（電話がありました。など）・対応（電話をいただきたい。など）・処理（処理済み・確認済み）

現況の「B:精算管理」「C:終了」「D:相談のみ」「E:相談不可」の値は、VA Case の終了処理と行の色に使います（4.5・4.8）。この4つの値は、名前を変えずに使ってください。

## 2.8 Excel 版からの移行（CSV の取り込み）

Excel の「VA事件データベースシリーズ」を使っていた事務所は、Excel のテーブルのデータを CSV にして、各ツールに取り込みます。

1. 各ツールで、新しい共有データを作り（2.6）、事務所の設定を入れておきます。事務所の設定（選択肢・フォルダ規則・保管先・所員など）は、CSV では取り込めません。
2. Excel で、テーブル（VA事件データベースの「事件」、VAファイル保管と VA領収書等ファイル保管の「保管」、VA電話メモの「電話メモ」）を、CSV で保存します（「CSV UTF-8（コンマ区切り）」か「CSV（コンマ区切り）」）。表の見出しの行が、CSV の1行目になるようにします。
3. ツールで［編集を始める］を押し、メニューの［ファイル］→［CSV から取り込む…（編集モード）］で、CSV を選びます。
4. 取り込む件数と、知らせること（読み替えた列の名前など）が出るので、確かめて［はい］を押します。

取り込みの決まりは、3.8 のとおりです。VA Case は、CSV の事件番号が共有データにすでにあると、1件も取り込みません。新しい共有データに取り込んでください。

# 第3章 4つのツールに共通の操作

## 3.1 画面の見方

4つのツールの画面は、同じ作りです。

- **上のメニュー：** ［ファイル］（最新を読み込む・CSV・この PC の設定・事務所の設定・閉じる）と［ヘルプ］があります。VA Case には［確認］［書類］、VA Filing・VA Receipt には［表示］もあります。
- **リボン：** ボタンを組ごとに並べています。左から「編集」の組（［編集を始める］［最新を読み込む］）、ツールの組、「検索」の組です。ボタンにマウスを重ねると、説明が出ます。
- **一覧（真ん中）：** 共有データの行を出します。行を選ぶと、その行が下のカードに出ます。
- **カード（下）：** 選んだ行の値を出す入力欄です。編集モードでは、ここで直します。
- **状態の欄（いちばん下）：** 左にモード（「閲覧モード」「編集モード（ほかの人は閲覧だけ）」。ほかの人が編集中なら、その人と PC の名前）と件数、右に、いま行ったこと（「読み込みました」「…を書き込みました」など）を出します。
- VA Filing・VA Receipt では、左にプレビュー（選んだ行のファイルの中身）があります（5.8）。

読み込みや書き込みは裏で行うので、その間も画面は使えます。裏で動いている間は、マウスのカーソルが回ります。

## 3.2 閲覧モードと編集モード

起動したときは、閲覧モードです。閲覧モードでは、見る・検索する・コピーする・CSV に出力する・ファイルやフォルダを開くことができ、直すことはできません。

**編集を始める**

1. リボンの［編集を始める］（オレンジの枠）を押します。
2. 編集モードになると、一覧の見出しがオレンジの地になり、カードの枠もオレンジになります。ウィンドウの題に「編集モード」と出ます。ボタンは［編集を終える］（青い枠）に変わります。
3. 編集モードの間、ほかの人は、そのツールを閲覧だけで使います。

ほかの人が編集中のときは、「〇〇さん（PC の名前、時刻から）が編集中です。閲覧だけできます。」と出て、閲覧モードのままです。編集を始めるのに時間がかかるときは、ボタンが点滅し、「モードを切り替えています…」と出ます。

**編集を終える**

［編集を終える］を押すと、閲覧モードに戻り、ほかの人が編集できるようになります。直した値がまだ書き込まれていなければ、先に書き込みます。使い終わったら、こまめに［編集を終える］を押してください。編集モードのままツールを閉じたときも、編集を終えてから閉じます。

- 編集モードでだけ使えるボタン（［新しい事件…］［消す］［ファイルを読み込む］など）は、閲覧モードでは灰色になります。
- 編集中に、ほかの PC の操作で編集の権利がなくなっていたときは、「編集の権利がなくなっていたため、閲覧モードに戻りました。」と出ます。

## 3.3 一覧の操作

**キー**

| キー | 働き |
|---|---|
| ↑・↓ | 選ぶ行を1行ずつ動かします。押し続けると、だんだん速く進みます |
| PageUp・PageDown | 1画面ずつ動かします |
| Home・End | 一覧の左端・右端を出します |
| Ctrl+Home・Ctrl+End | 最初の行の左端・最後の行の右端へ動きます |
| ←・→ | 一覧を左右に動かします |
| Enter | カードの入力の欄へ移ります（VA Case・VA Filing は事件呼名、VA Receipt は種別、VA Call は相手先） |
| Shift＋マウスのホイール | 一覧を左右に動かします |

矢印キーで行を送っている間は、カード（とプレビュー）の書き換えを待ち、キーを離すと出します。

**何行かを選ぶ**

- 一覧の上をマウスでなぞる、Shift を押しながらクリックする、Shift+↑・↓ で、続いた何行かを選べます。
- 何行かを選んでいる間、カードには、クリックした行（なぞったときは、なぞり始めた行）を出します。

**行をコピーする**

- Ctrl+C か、リボンの［コピー］で、選んだ行の、一覧に出している列を、タブで区切ってコピーします。Excel などに、そのまま貼り付けられます（見出しは付きません）。何行かを選んでいれば、その全部をコピーします。［コピー］は閲覧モードでも使えます。

**セルの文字をなぞって選ぶ**

- セルの中で文字をなぞると、その文字を選べます。続けて Shift+←・→ で、選ぶ範囲を1字ずつ変えられます。
- 選んだ文字は、Ctrl+C でコピーします。リボンの［コピー］は、文字を選んでいても、行をコピーします。
- 折り返して何行かになったセルでも選べます。コピーするのは、折り返しの改行を除いた、元の値の文字です。

**列の幅と折り返し**

- すべてのセルは、列の幅で折り返して出します。列の見出しの境目をドラッグすると、列の幅を変えられます。
- 列の幅は、閉じるときに覚え、次に起動したときに戻します（PC ごと）。

## 3.4 検索とフィルタ

**検索**

1. リボンの「検索」の組の欄に、探す語を入れます。語は空白で区切って、いくつも入れられます。
2. 「OR」（どれか1つを含む行）か「AND」（すべてを含む行）を選びます。
3. Enter か［結果を表示］を押すと、当てはまる行だけを出します。

- 一覧に出していない列（VA Case のカードにだけ出す列など）も含めて、すべての列から探します。
- 次の違いは、同じ字とみなします：異字体（高と髙、斉と齋と斎など）、全角と半角、英字の大文字と小文字、ひらがなとカタカナ、濁点・半濁点の有無（が と か）、小さい字（っ と つ）。長音（ー）とハイフンは除いて比べます（サーバ と サーバー）。
- 語が日付として読めるときは、日付の値と日で比べます（2025/1/1 で R7.1.1 も、R7.1.1 で 2025-01-01 も見つかります）。
- 状態の欄の件数は、「検索の結果 5 件（全 120 件）」のように出ます。

**フィルタ**

1. 一覧の列の見出しをクリックすると、その列の値の一覧が出ます。
2. 出したい値に印（☑）を付け、［OK］を押します。［すべて選ぶ］［すべて外す］、値を探す欄も使えます。
3. フィルタを掛けた列の見出しには ▼ が付きます。

- 何列かに掛けると、すべてに当てはまる行だけを出します。検索とも一緒に使えます。
- セルの中に何行かある値（相手方が2人など）は、1行ずつを値として並べます。空のセルは「（空白）」です。
- 1つの列のフィルタだけを外すときは、見出しをクリックして［この列のフィルタを解除］を押します。

**すべてを表示**

リボンの［すべてを表示］を押すと、検索とすべての列のフィルタを外して、すべての行を出します。検索もフィルタも掛けていない間は、灰色です。フィルタは、閉じると外れます（覚えません）。［最新を読み込む］や書き込みの後は、掛けたままです。

## 3.5 カードと入力の助け

カードは、一覧で選んだ行の値を出す入力欄です。閲覧モードでは見るだけで、編集モードで直せます。閲覧モードでも、欄の文字をなぞって選び、Ctrl+C でコピーできます。Tab で次の欄へ移ります。

**オートコンプリート**

欄の名前に下線が付いた欄は、入力すると、これまでに入れた値から続きを補います（Excel のオートコンプリートと同じです）。

- 入れた字で始まる値が1つに決まったときに、残りの部分を選んだ状態で補います。2つ以上あるうちは補いません。
- 続けて打つと、補った部分は打った字に置き換わります。Enter や Tab で、補った値に決まります。
- 全角と半角、英字の大文字と小文字は問わずに比べます。
- 何行かの欄では、カーソルのある行ごとに補います。

下線の付く欄は、VA Case が裁判所名・事件名・代理人・代理人住所・代理人電話番号・代理人FAX番号、VA Filing が事件呼名・内容、VA Receipt が相手先、VA Call が相手先・電話番号です。

**日付の書き方**

| ツール | 欄 | 入れられる書き方 |
|---|---|---|
| VA Case | 生年月日・相談年月日・終了年月日 | R7.1.1・令和7年1月1日・H31.4.30 などの和暦、2025/1/1・2025-01-01・2025年1月1日 などの西暦（全角の数字も可）。画面には R7.1.1 の形で出ます |
| VA Filing | 日時 | 上の書き方と、時刻（10:30・10時30分）。12桁の数字（202511011030）にそろえます |
| VA Receipt | 日時 | 上の書き方。8桁の数字（20251101）にそろえます |
| VA Call | 日時 | 2025/11/9 10:30・2025-11-09 10:30 などの西暦と時刻 |

- 年を省いた書き方（11/1 など）は読みません（年の変わり目に、違う年になるおそれがあるためです）。
- VA Case の生年月日は、依頼者が何人かいるときに、1行に1人ずつ入れられます（依頼者氏名と同じ順に並べます）。
- 読めない日付は、書き込むとき（VA Filing・VA Receipt は［保管する］のとき）に知らせます。

## 3.6 書き込むときと、元に戻す（Ctrl+Z）

**書き込むとき**

VA Case のカードと VA Call の入力欄で直した値は、次のときに、自動で共有データに書き込みます。［書き込む］のボタンはありません。

- ほかの行（事件・メモ）を選んだとき
- ［新しい事件…］［新しいメモ］を押したとき、書類を作るとき（VA Case）、メールを送るとき（VA Call）
- ［編集を終える］［最新を読み込む］を押したとき、ツールを閉じるとき

直して、まだ書き込んでいない値は、一覧にも青い字で出します。書き込む前に確かめで止めたとき（日付が読めないなど）は、知らせて、その行に留まります。書き込めなかった値は、画面を閉じるまで残し、閉じるときに確かめます。

VA Filing・VA Receipt では、未保管の行に入れた値は、行ごとに覚えておき、［保管する］を押したときに書き込みます。保管済みの行の備考は、ほかの行に移るとき・備考の欄で Enter を押したときなどに書き込みます。

**元に戻す・やり直す**

- Ctrl+Z で、入力欄で直した値を、直した順に1つずつ戻します。Ctrl+Y で、やり直します。カードの欄でも、一覧でも効きます。
- 1つの欄で続けて打った分は、まとめて1回で戻ります。戻した欄に、カーソルが移ります。
- 戻せるのは、その行をカードに出している間（書き込むまで）です。ほかの行に移って書き込んだ後は、戻せません。
- VA Filing・VA Receipt の［保管する］は、Ctrl+Z では戻りません。［保管を取り消す］を使います（5.7）。

## 3.7 最新を読み込む

リボンの［最新を読み込む］（メニューの［ファイル］→［最新を読み込む］、F5）を押すと、共有データを読み直し、ほかの人が書き込んだ変更を一覧に出します。直した値がまだ書き込まれていなければ、先に書き込みます。

閲覧モードの間は、ほかの人の変更は自動では出ません。見るときに［最新を読み込む］を押してください。［編集を始める］を押したときは、最新の共有データを読み直してから編集モードになります。

## 3.8 CSV の出力と取り込み

**CSV に出力**

メニューの［ファイル］→［CSV に出力…］で、一覧の表を CSV にします。

- 文字コードは UTF-8（BOM 付き）で、Excel で開いても文字化けしません。1行目は列の名前です。日付は 2025-01-01 の形です。
- VA Case は、検索・フィルタで絞っているときに、絞った事件だけを出力するかを尋ねます。ほかのツールは、すべての行を出力します。
- CSV には、氏名・住所などがそのまま入っています。使い終わったら消すなど、置き場所に気をつけてください。

**CSV から取り込む**

編集モードで、メニューの［ファイル］→［CSV から取り込む…（編集モード）］を押し、CSV を選びます。

- 今の共有データに足します（入れ替えではありません）。今ある記録は消さず、書き換えません。
- 取り込むのは一覧の表だけで、事務所の設定は取り込みません。
- 文字コードは、UTF-8（BOM の有無を問わない）と Shift_JIS を読みます。
- 列は、1行目の列の名前で合わせます（列の順は問いません）。全角と半角・空白・英字の大小の違いは読み替えます（「代理人ＦＡＸ番号」→「代理人FAX番号」など）。読み替えたことは、取り込む前に知らせます。
- このツールにない名前の列があると、1件も取り込まずに止め、このツールの列のうち CSV にないものも示します（列の名前の打ち間違いで、データを失わないためです）。同じ名前の列が2つあるときも止めます。
- CSV にない列は空にして取り込み、そのことを取り込む前に知らせます。ただし、VA Case の「事件番号」の列がないと、取り込めません。
- 日付の列は、和暦（R7.1.1）・西暦を読み取ります。

ツールごとの決まり：

- VA Case：事件番号が空・数でない、共有データにすでにある、CSV の中で重なる事件があれば、1件も取り込まず、問題の行をすべて示します。
- VA Filing・VA Receipt・VA Call：番号が空か、すでにある番号なら、新しい番号を付けて足します。番号のほかの値が、すでにある記録と同じ行は取り込みません（同じ CSV を2回取り込んでも、二重になりません）。CSV の中に同じ行が2つあるときは、両方を取り込みます。

## 3.9 バックアップ

「この PC の設定」でバックアップのフォルダを決めておくと、その日の最初に共有データを読み込んだときに、共有データの写しを `yyyymmdd_VA_Case.json`（ツールごとの名前）として置きます。

- その日の分がすでにあるとき（ほかの PC が作ったときも）と、データが1件もないときは、作りません。
- 古いバックアップは消しません。要らなくなったものは、手で消してください。
- バックアップのフォルダが見つからないときは、作らずに知らせます。
- バックアップには、共有データと同じく事件の情報が入っています。置き場所に気をつけてください。

バックアップから戻す方法は、10.2 にあります。

## 3.10 ヘルプと診断情報

メニューの［ヘルプ］から、次の操作ができます。

- **診断情報をコピー：** ツールの版・OS・画面の大きさ、この PC の設定（場所の欄は、あるか・見つからないか・設定なしか、とドライブの種類だけ）、モードなどの状態、共有データの版と、表ごとの行数・列ごとの値の数と長さ、起きた誤りの種類と場所（プログラムのファイル名・行・関数名。新しいものから 10 件）だけをまとめた文を、クリップボードにコピーします。**氏名・住所などの値、ファイルやフォルダの場所と名前、利用者と PC の名前、誤りのメッセージの本文は入りません。** 不具合を作成者や AI に相談するときは、この診断情報を貼り付けて渡してください。渡す前に、メモ帳などに貼り付けて、中身を確かめられます。
- **VA Case について**（ツールごとの名前）：名前と版、ライセンスを表示します。

誤りの記録は、ツールを閉じた後や止まった後でも渡せるよう、この PC の設定と同じフォルダの `<ツール>_errors.json` に、新しいものから 30 件を覚えます。

不具合を相談するときは、どの操作で起きたかも、言葉で添えてください。画面に出たメッセージには、ファイルやフォルダの名前（依頼者の名前が入っていることがあります）が入っていることがあります。メッセージを写して渡すときは、その部分を伏せてください。

# 第4章 VA Case

## 4.1 画面

一覧には、事件番号・現況・事件呼名・受任区分・事件区分・担当区分・依頼者氏名・関係者・相手方氏名・代理人・裁判所名・裁判所事件番号・事件名の13列を出します。ほかの列（住所・電話番号・データフォルダなど）は、下のカードに出します。検索は、すべての列で行います。

事件の並びは、現況・受任区分・事件区分・事件番号の順です。

カードには、32の欄を4列に並べています。

| 列 | 欄 |
|---|---|
| 事件 | 事件番号・現況・事件呼名・受任区分・事件区分・担当区分・相談弁護士・相談年月日・終了年月日 |
| 依頼者・関係者 | 依頼者氏名・ふりがな・生年月日・住所・電話番号・メールアドレス・関係者・相談内容 |
| 相手方・代理人 | 相手方氏名・相手方ふりがな・相手方住所・相手方電話番号・代理人・代理人住所・代理人電話番号・代理人FAX番号 |
| その他 | 裁判所名・裁判所事件番号・事件名・依頼人立場・データフォルダ・TeamsURL・備考 |

- 現況・受任区分・事件区分・担当区分・相談弁護士・依頼人立場は、事務所の設定の選択肢から選びます（相談弁護士は担当区分から選びます）。
- 何人かの相手方などは、欄の中で改行して、1行に1人ずつ入れます。何行かの欄は、スクロールバーで見ます。
- ふりがなは、手で入れます（VA Filing の事件呼名の並びに使います）。
- データフォルダ・TeamsURL の欄の右の［開く］で、データフォルダをエクスプローラーで開く、TeamsURL を開くことができます（書き込んだ値の場所を開きます）。

リボンの組は、「編集」、「事件」（［新しい事件…］［コピー］［消す］）、「書類」（［事件メモ］［期日請書…］［送付書…］）、「検索」です。

## 4.2 事件番号の付け方

［新しい事件…］を押すと、新規の依頼人か、選んでいる事件と同じ依頼人かを尋ね、次のように番号を付けます。

- **新規の依頼人：** いまある最大の事件番号を 100 で割った整数部に 100 を掛け、101 を足します（例：最大が 1234 なら 1301）。下2桁が依頼人ごとの事件の番号、その上が依頼人の番号になります。事件が1件もないときは 101 です。
- **同じ依頼人：** 選んでいる事件の番号を 100 で割った整数部が同じ事件のうち、最大の番号に1を足します（例：1301 の依頼人の2件目は 1302）。

事件番号は、編集モードのカードで直せます（番号の重なりを直すとき、年を頭に入れた番号にするときなど）。たとえば、頭に西暦の下2桁を付けた番号（2026年の最初の依頼人を 2600101 など）にしたいときは、その年の最初の事件だけ番号を手で直すと、以後の番号はそれに続きます。

- 番号は数で入れます。頭の 0 は付けません。
- すでにある番号には変えられません。番号を変えるときは、確かめてから書き込みます。

## 4.3 新しい事件を足す・消す

**新しい事件**

1. 編集モードで、リボンの［新しい事件…］を押します。
2. 「追加するのは、新規の依頼人ですか？」に答えます。［いいえ］を選ぶと、一覧で選んでいる事件と同じ依頼人の事件として番号を付け、依頼者（氏名・ふりがな・生年月日・住所・電話番号・メールアドレス）・関係者・相手方（氏名・ふりがな・住所・電話番号）・代理人（氏名・住所・電話番号・FAX番号）の欄を写します。調停の後の訴訟など、同じ争いの続きで、入れ直さずに済みます。
3. 番号を付けた空の事件をすぐに書き込み、カードに出します。事件呼名などを入れます（ほかの事件に移るときなどに書き込みます。3.6）。

編集モードで、一覧の事件番号の列をダブルクリックしても、［新しい事件…］と同じく事件を足せます（同じ依頼人を選ぶと、ダブルクリックした事件の依頼人になります）。ほかの列をダブルクリックすると、カードの事件呼名の欄へ移ります。

事件呼名が空のまま書き込むときは、確かめます。

**事件を消す**

編集モードで事件を選び、リボンの［消す］を押します。確かめてから消します。データフォルダは消しません。

**代理人の住所などの補い**

代理人の欄に入れた名前が、これまでの事件の代理人と同じなら、代理人住所・代理人電話番号・代理人FAX番号に、その事件の値を入れます。

- 新しい事件から探し、欄ごとに、最初に見つかった値を使います。
- 自分で入れた値は変えません（欄が空か、前に自動で入れた値のときだけ入れます）。
- 代理人が何人かいるときは、代理人と同じ行に入れます。

## 4.4 現況と終了年月日

現況を「C:終了」にして書き込むとき、終了年月日が空なら、今日の日付を入れるかを尋ねます。

現況を「C:終了」か「B:精算管理」にして書き込むと、データフォルダの終了処理（ZIP）を始めるかを尋ねます（4.8）。現況が「C:終了」「B:精算管理」でない事件を書き込むときに、データフォルダが見つからなければ、「データフォルダの値が不正か、フォルダが存在しません。」と知らせます。

## 4.5 行の色

| 一覧の字の色 | 意味 |
|---|---|
| 灰色 | 現況が「C:終了」 |
| 緑 | 現況が「D:相談のみ」 |
| 橙 | 現況が「E:相談不可」 |
| 赤 | ［確認］→［データフォルダの確認］で、データフォルダが見つからなかった事件 |
| 青 | カードで直して、まだ書き込んでいない値がある事件 |

閲覧モードでは1行おきに淡い灰色、編集モードでは淡いオレンジの地にします。

## 4.6 書類（事件メモ・期日請書・送付書）

一覧で事件を選び、リボンの「書類」の組（メニューの［書類］）から作ります。閲覧モードでも作れます。カードで直した値があれば、先に書き込んでから作ります。

作った PDF は、その事件のデータフォルダに `yyyymmdd_書類の名前_事件呼名.pdf`（例：`20261114_事件メモ_甲野太郎（貸金）.pdf`）の名前で保存し、ふだん使う PDF のソフトで開きます。印刷は、そのソフトから行います。

- 同じ日の同じ書類があれば、置き換えるかを尋ねます。
- データフォルダが見つからないとき（終了処理で ZIP にした事件も）は、保存する場所を選んでもらいます。
- 事件呼名のうち、ファイルの名前に使えない字は全角にします。事件呼名が空なら、事件番号を使います。

**事件メモ**

事件の情報を、A4 の縦1枚にまとめた PDF です。事件番号・データフォルダ・裁判所名・事件名・裁判所事件番号、当事者（依頼者と相手方。依頼人立場から、原告・被告などの立場を書きます）と代理人、期日と書証の記入欄などを書きます。裁判所の電話番号・FAX 番号は、事務所の設定の「裁判所」に、その裁判所があれば書きます（裁判所名の欄が何行かあるときは、最後の行で探します）。当事者・代理人が4人以上のときは、2ページ目に続きを書きます。

**期日請書**

［期日請書…］を押すと、次の欄を入れる画面が開きます。［PDF を作る］で作ります。

- 裁判所（事件の裁判所名の最後の行が入っています）
- 期日の名前（第1回口頭弁論期日・弁論準備手続期日などから選ぶか、入れます）
- 日時（例：R7.12.1 10:30。和暦・西暦のどちらでも。時刻は 24 時間で）
- 弁護士名（事務所の設定の「担当区分の詳細」に、その事件の担当区分の弁護士の氏名を入れておくと、出ます。2人以上のときは「・」で区切って入れ、最初の人が既定になります）

**送付書**

［送付書…］を押すと、直送の送付書と受領書の PDF を作る画面が開きます。

- 裁判所と、その FAX 番号（事務所の設定の「裁判所」にあれば入っています）
- 相手方代理人と、その FAX 番号（事件の代理人・代理人FAX番号の1行目が入っています）
- 当職（弁護士名）、次回期日（任意）
- 送付書類（8行まで。書類の名前と枚数）
- 後日クリーンコピー提出（送付した書面全部・答弁書・準備書面・書証）

事務所の電話番号・FAX 番号は、事務所の設定の「事務所」に入れておくと、送付書に書きます。

## 4.7 データフォルダの確認

メニューの［確認］→［データフォルダの確認］で、データフォルダが見つからない事件を探します。見つからない事件は一覧に示し、一覧では赤い字にします。終了処理で ZIP にした事件は、確かめません。

## 4.8 終了処理（データフォルダの ZIP）

現況を「C:終了」か「B:精算管理」にして書き込むと、事件のデータフォルダを ZIP にして、「移送待ち」のフォルダに置きます。保管庫への移送は、利用者が行います（8.4）。

**前もって決めておくこと**

- 「この PC の設定」の「移送待ちの場所」（日常の共有フォルダの中のフォルダ）。
- 事務所の設定の「フォルダ規則」：現況・受任区分・事件区分ごとに、保管庫の中のどの場所に置くかを、保管庫の中の相対の場所で書きます（例：`個人一般\yyyy`）。`yyyy` は、終了年（終了年月日の年。2017年以前は `-2017`）に置き換わります。ドライブ名などで始まる場所（`E:\終了事件\…` など）は使えません。表には担当区分の列もありますが、場所を決めるときには使いません。

**流れ**

1. 現況を変えて書き込むと、元のフォルダと置き場所（`移送待ち\個人一般\2026\<データフォルダの名前>.zip` など）を示して、ZIP にするかを尋ねます。
2. ［はい］を押すと、ZIP を作り始めます。進み具合が出て、［取り消す］で取り消せます。作っている間も、VA Case は使えます。OneDrive・SharePoint のフォルダで、手元にないファイルは、ダウンロードしながら作るので、時間がかかります。
3. ZIP を作り終えると、中身（ファイルの数と、壊れていないか）を確かめてから、元のデータフォルダを消すかを尋ねます。［いいえ］を選んだときは、元のフォルダは残るので、確かめてから手で消してください。
4. 事件のデータフォルダの欄は、「保管庫：個人一般/2026/<データフォルダの名前>.zip」の形になります（元の場所も、欄の後ろに残します。現況を戻したときに使います）。

- ZIP は、データフォルダの名前のフォルダを中に含む形（エクスプローラーの「圧縮」と同じ形）で作ります。既定は無圧縮です。
- 同じデータフォルダを、ほかの事件も使っているとき（依頼人ごとのフォルダなど）は、まだ終わっていない事件があれば、ZIP にしません。最後の事件が終わったときに、まとめて ZIP にし、それらの事件のデータフォルダの欄も、すべて保管庫の値にします。
- ZIP にした事件のデータフォルダは、VA Case からは開きません。［開く］を押すと、保管庫の中の場所を示すので、保管庫を開いて、エクスプローラーで探してください（保管庫へ移す前なら、移送待ちの同じ場所にあります）。
- 次のときは、ZIP にせずに知らせます：データフォルダが空・見つからない、合うフォルダ規則がない、移送待ちの場所が決まっていない・見つからない、移送待ちに同じ名前の ZIP がある。

## 4.9 終了処理を戻す

終了処理をした事件の現況を「A:未了」など（「C:終了」「B:精算管理」以外）に戻して書き込むと、データフォルダを元に戻します。

- 元のデータフォルダが残っていれば、データフォルダの欄を元の場所に戻すだけです。
- 元のフォルダを消してあり、移送待ちに ZIP があれば、ZIP を元の場所に展開してから、欄を戻します（元の場所の記録がなければ、展開する場所を選んでもらいます）。欄を戻した後、移送待ちの ZIP を消すかを尋ねます。残したときは、保管庫へ移さないよう、手で消してください。
- 移送待ちに ZIP がないとき（保管庫へ移した後）は、VA Case は保管庫に触れないため、戻しません。保管庫の中の場所を示すので、保管庫を開いて ZIP を展開し、データフォルダの欄に、展開した場所を入れてください。
- 同じ ZIP にまとめたほかの事件のデータフォルダの欄も、戻した場所に直します（現況は変えません）。

# 第5章 VA Filing

## 5.1 画面

左にプレビュー、右に一覧と入力欄があります。一覧には、番号・読込フォルダ名・読込ファイル名・日時・事件呼名・内容・保管フォルダ名・保管ファイル名・複製作成先・保管日時・備考を出します。保管済みの行は灰色の字、書き込み中・書き込み待ちの行は、字が点滅します。

入力欄の一番上に、番号と読込ファイル（なぞって選び、Ctrl+C でコピーできます）、［ファイルを開く］、行の状態（未保管・保管済み・書き込み中）を出します。その下に、日時・事件呼名・内容・保管フォルダ・保管ファイル名・複製作成先・備考の欄と、［保管する］［保管を取り消す］があります。

- 一覧の行をダブルクリックすると、ファイルを開きます（保管済みなら保管した場所のファイル、未保管なら読込フォルダのファイル）。保管フォルダ名・読込フォルダ名の列をダブルクリックすると、そのフォルダを開きます。
- 起動すると、最初の未保管の行を選びます。

リボンの組は、「編集」、「ファイル」（［ファイルを読み込む］［コピー］［消す］）、「検索」です。

**ふだんの流れ**

1. ［編集を始める］を押します。
2. ［ファイルを読み込む］を押して、読込フォルダのファイルを一覧に足します（5.2）。
3. 未保管の行で、事件呼名を選び、内容を入れ、［保管する］を押します（5.4）。次の未保管の行へ進みます。
4. 終わったら、［編集を終える］を押します。

## 5.2 ファイルを読み込む

編集モードで、リボンの［ファイルを読み込む］（メニューの［ファイル］→［読込フォルダのファイルを読み込む］）を押すと、事務所の設定の「読込フォルダ」にあるファイルを、一覧に足します。

- 「サブフォルダも」を「はい」にした読込フォルダは、中のフォルダのファイルも読み込みます（名前が「.」で始まるフォルダは除きます）。
- すでに未保管の行にあるファイルは、足しません。前に保管したファイルと同じ名前の新しいファイルは、足します。
- 読込フォルダからなくなった未保管の行は、消します。
- 次のファイルは読み込みません：Thumbs.db・desktop.ini・.DS_Store、名前が「.」「~$」で始まるもの、名前が .tmp・.part・.crdownload で終わるもの、事務所の設定の「読み込まないファイル名の先頭」で始まるもの。
- 読み込んだ件数と、見つからなかった読込フォルダを知らせます。

## 5.3 番号と日時

**番号**

読み込んだ行には、年月日6桁（yymmdd）とその日の連番3桁の9桁の番号を付けます（例：261114001 は、2026年11月14日の1件目）。年月日は、読み込んだときのパソコンの日付です。VA Receipt・VA Call の番号も同じ付け方です。CSV から取り込んだ、これまでの番号は、そのまま残します。

**日時**

日時の欄は、12桁（yyyymmddhhnn）です。ファイル名の先頭の12字が「20」で始まる数字なら、それを使い、そうでなければファイルの更新日時を入れます。日時の欄に別の書き方（2025/11/1・R7.11.1・令和7年11月1日 10時30分など）を入れると、欄を出たとき・Enter を押したときに12桁にそろえます。日付だけのときの時刻は 0000 です。日時は空でも保管できます。

## 5.4 保管する

1. 一覧で未保管の行を選びます。
2. 事件呼名を選びます（5.5）。保管フォルダと複製作成先が入ります。
3. 内容（「準備書面」「判決正本」など）を入れます。保管ファイル名が自動で入ります。
4. ［保管する］を押します。

ファイルを保管ファイル名にして保管フォルダへ移し、決まっていればショートカットや写しを作り（5.6）、記録を書き込みます。終わるのを待たずに、次の未保管の行へ進みます。書き込み中に次の行を保管すると、待ち行列に入れて順に行います。

- 事件呼名・内容・保管フォルダが空のとき、日時を読めないとき、保管ファイル名にファイル名に使えない字があるときは、知らせて止めます。
- 保管する前に、読込ファイル・保管フォルダ・写しの置き場所があるか、同じ名前のファイルがないかを、すべて確かめます。1つでも問題があれば、何も動かさずに止めます。
- 保管フォルダ・写しの置き場所のフォルダは作りません。見つからなければ止めます（8.2）。
- 途中で失敗したときは、それまでにしたことを戻します（ファイルを読込フォルダへ戻し、作った写しを消します）。
- 別のドライブへ移すときは、写してから大きさを確かめ、それから元のファイルを消します。
- ファイルがほかのソフトで開かれていると、移せないことがあります。閉じてから、もう一度押してください。
- 内容の欄で Enter を押すと、［保管する］へ移ります。

未保管の行で入れかけた値は、ほかの行に移っても行ごとに覚えています（共有データには、［保管する］まで書きません）。

保管済みの行で直せるのは、備考だけです。ほかの欄は、入力欄に見えない形（地の色が窓と同じで、枠がない形）で出します。

## 5.5 事件呼名と保管フォルダ・保管ファイル名

**事件呼名を選ぶ**

事件呼名の欄では、次のものから選べます。打った字で、候補を絞り込めます（事件呼名・ふりがな・依頼者氏名で探します）。

- VA Case の、終了していない事件（ふりがなの順）。終了した事件（現況が「C:終了」の事件と、終了処理で ZIP にした事件）は出ません。
- 事務所の設定の「保管先」にある、VA Case にない保管先（「（文献）」など）

保管フォルダが決まっていないもの（データフォルダが空の事件など）は、候補に出ません。

**保管フォルダ**

事件呼名を選ぶと、保管フォルダには、その事件の VA Case のデータフォルダが入ります。データフォルダと違う場所に保管すると、その場所を事件呼名ごとに覚え（事務所の設定の「保管先」）、次からはそこが入ります。データフォルダの中のフォルダ（scan など）に保管したときは、「（データフォルダ）\scan」の形で覚えます（データフォルダの名前や場所を変えても、既定が切れません）。

- 保管フォルダの欄の右の［参照…］でフォルダを選び、［開く］でエクスプローラーで開けます。
- 保管フォルダが見つからない保管先は、候補に出しません。見つからない保管先と、VA Case で終了した事件の保管先は、次に保管するときに「保管先」の表から消します。ただし、覚えた保管フォルダが1つも見つからないとき（暗号化したドライブを開き忘れたときなど）は、見つからないとはみなしません。

**保管ファイル名**

保管ファイル名は、日時・事件呼名・内容から、次の形で自動で入ります。直すこともできます（直した後は、日時・内容を変えても、自動では変えません）。

```
<日時（12桁）>00000<事件呼名>　<内容><拡張子>
例：20251101103000000甲野太郎（貸金）　準備書面.pdf
```

事件呼名と内容の間は、全角の空白です。事件呼名が「（文献）」で終わるときは、`<内容><拡張子>` だけにします。

## 5.6 ショートカットと写し

**複製作成先**

入力欄の「複製作成先」には、事件の担当区分が入ります（選び直せます）。事務所の設定の「複製作成先」に、担当区分ごとに、種類（ショートカット・コピー）とフォルダ（担当者の未確認のフォルダなど）を入れておくと、保管したときに、そのフォルダに次のものを作ります。

- ショートカット：保管したファイルへのショートカット（`<保管ファイル名>.lnk`）。Windows でだけ作ります。
- コピー：保管したファイルの写し

1つの担当区分に、何行でも入れられます。

**特別な写し**

事務所の設定の「特別な写し」に、語とフォルダを入れておくと、内容にその語が入っているファイルを保管したときに、そのフォルダに写しを作ります（例：「職務上請求」「弁護士会照会」）。フォルダが空の行は、写しを作りません。作ったときは、そのことを知らせます。

## 5.7 保管を取り消す・消す

**保管を取り消す**

保管済みの行を選び、［保管を取り消す］を押すと、確かめてから、保管したファイルを元の読込フォルダへ戻し、行を未保管に戻します。作ったショートカット・写しも消します（見つからなかった写しは、知らせます）。入力欄の Ctrl+Z では、保管は取り消せません。

**消す**

未保管の行を選び、リボンの［消す］を押すと、確かめてから、行を消し、読込フォルダのファイルをごみ箱へ移します（ごみ箱から戻せます）。

- 保管済みの行は消せません。先に［保管を取り消す］で読込フォルダへ戻してください。
- ネットワーク上のフォルダ（暗号化した仮想ドライブの中を含みます。8.1）のファイルは、ごみ箱へ移せない（戻せなくなる）ため、消しません。エクスプローラーで消してから、［ファイルを読み込む］を押してください（行は、読み込んだときに消えます）。
- 読込フォルダにファイルがもうないときは、行だけを消します。

## 5.8 プレビューと字の読み取り

一覧で行を選ぶと、左のプレビューに、そのファイルの中身を出します。

- 出せるのは、PDF と画像（JPG・PNG・TIFF・BMP・GIF）です。ページを上から縦に並べ、マウスのホイールかスクロールバーで送ります。並べるのは 50 ページまでです（それより後は［ファイルを開く］で見ます）。100 MB を超えるファイルは出しません。
- プレビューと一覧の境目をドラッグすると、プレビューの幅を変えられます。メニューの［表示］→［プレビュー］で、出す・出さないを切り替えます。幅と出すかは、閉じるときに覚えます。
- 読み込みは裏で行い、その間も画面は使えます。ファイルは、中身を読んだらすぐ閉じます（保管でファイルを移すときに、使用中で失敗しないためです）。

**字を選んでコピーする**

プレビューの字の上をなぞって選び、Ctrl+C（または右クリックの［コピー］）でコピーできます。入力欄（内容など）に Ctrl+V で貼り付けられます。

- ダブルクリックで語を、トリプルクリックで行を、Ctrl+A（右クリックの［このページの文字をすべて選ぶ］）でページの字をすべて選びます。Shift+←・→ で、選んだ範囲を1字ずつ変えられます。
- PDF に字が入っていれば、その字を使います。入っていないとき（スキャンした PDF・受信した FAX・写真）は、Windows の文字認識で、ページの画像から字を読み取ります。読み取りは、この PC の中だけで行い、外部には送りません。
- **文字認識は、字を読み違えることがあります。** 読み取った字を使ったときは、元の画像と見比べて、必ず確かめてください（とくに数字・金額・日付・氏名）。
- 日本語の文字認識が入っていない PC と Mac では、画像の字は読み取れません（そのことを知らせます）。

# 第6章 VA Receipt

## 6.1 画面と流れ

画面と操作は、VA Filing と同じです（左にプレビュー、右に一覧と入力欄。5.1・5.8）。一覧には、番号・読込フォルダ名・読込ファイル名・種別・日時・相手先・金額・枝番・保管フォルダ名・保管ファイル名・保管日時・備考を出します。入力欄は、種別・日時・相手先・金額・枝番・保管フォルダ・保管ファイル名・備考です。

**ふだんの流れ**

1. ［編集を始める］を押し、［ファイルを読み込む］で、読込フォルダのファイルを一覧に足します（読み込みの決まりと番号の付け方は、VA Filing と同じです。5.2・5.3）。
2. 未保管の行で、種別・日時・相手先・金額を確かめ、［保管する］を押します。次の未保管の行へ進みます。
3. 終わったら、［編集を終える］を押します。

金額の欄で Enter を押すと、［保管する］へ移ります。

## 6.2 種別と保管フォルダ

事務所の設定の「種別と保管フォルダ」に、種別ごとの保管フォルダを入れておきます。

- 入力欄で種別を選ぶと、その保管フォルダが入ります。種別は、表の中から選ぶだけです。
- 表の1つ目の種別が、読み込んだファイルの種別の既定になります。並べた順に、選択肢に出ます。

## 6.3 日時・相手先・金額

ファイルを読み込むと、ファイル名から日時・相手先・金額を入れます。ファイル名を `<日付8桁>_<相手先>_<金額>` の形（例：`20251101_丙野書店_1100.pdf`）にしておくと、そのまま保管できます。

- ファイル名が8桁の数字で始まらないときは、相手先・金額は入れません。
- 日時：ファイル名の先頭の8字が「20」で始まる日付なら、それを入れます。そうでなければ、事務所の設定の「日時」が「ファイルの日付」ならファイルの更新日（スキャンした日など）を、「空欄」なら入れずに、保管するときに入れてもらいます。日時の欄は8桁（yyyymmdd）で、別の書き方（2025/11/1・R7.11.1 など）を入れると、8桁にそろえます。
- 金額：数字だけにそろえます（「1,100円」「￥1,100」「１１００」は「1100」に。「-500」「▲500」は「-500」に）。
- Windows がファイルを写したときに名前に付ける「 (2)」「 - コピー」は除いてから読みます。

種別・日時・相手先・金額が空のとき、日時が読めないとき、金額が数字にならないときは、［保管する］で知らせて止めます。

## 6.4 枝番と保管ファイル名

保管ファイル名は、次の形で自動で入ります（直すこともできます）。

```
<日時>_<相手先>_<金額><拡張子>
枝番があるとき：<日時>_<相手先>_<金額>_<枝番><拡張子>
例：20251101_丙野書店_1100.pdf、20251101_丙野書店_1100_1.pdf
```

金額が空で枝番もないときは、`<日時>_<相手先><拡張子>` です。

**枝番**

日時・相手先・金額が同じファイルを区別する番号です。事務所の設定の「枝番」で、付け方を選びます。

- 重なるときだけ付加する（既定）：同じ日時・相手先・金額のファイルの2件目から、1・2…を付けます。
- 常に付加する：1件目から 1 を付けます。

保管済みのファイルや、保管フォルダにすでにあるファイルと名前が重なるときは、重ならなくなるまで枝番を増やします。枝番は手で直せます（数字で入れます。付けないときは 0 か空）。

## 6.5 保管する・取り消す・消す

［保管する］［保管を取り消す］［消す］は、VA Filing と同じです（5.4・5.7）。VA Receipt は、ショートカットと写しを作りません。

# 第7章 VA Call

## 7.1 画面

一覧には、番号・入力者・日時・相手先・電話番号・用件・対応・内容・宛先・メール送信日時・確認者・処理を出します。処理を入れたメモは灰色の字、直して書き込んでいないメモは青い字です。起動すると、いちばん新しいメモを選びます。

入力欄は、入力者・日時・相手先・電話番号・用件・対応・内容・宛先・確認者・処理です。入力者・宛先・確認者は所員から、用件・対応・処理は事務所の設定の選択肢から選びます。内容は6行の欄で、長い内容はスクロールバーで見ます。右下に、メール送信日時と［メールを送る…］があります。

リボンの組は、「編集」、「メモ」（［新しいメモ］［コピー］［消す］）、「検索」です。

## 7.2 新しいメモと入力者

編集モードで、リボンの［新しいメモ］を押すと、番号・入力者・日時を入れた空のメモをすぐに書き込み、入力欄に出します。続けて相手先などを入れます（ほかのメモに移るときなどに書き込みます。3.6）。

- 番号は、年月日6桁とその日の連番3桁の9桁です（5.3）。
- 日時は、いまの日時です。
- 入力者には、事務所の設定の「所員」で、「ユーザー名（Windows）」がこの PC の Windows のユーザー名と同じ所員の所員名が入ります。事務所の設定の「所員」のタブに、この PC のユーザー名を示しています。

## 7.3 相手先と電話番号の補い

相手先に入れた名前が、これまでのメモの相手先と同じなら、そのいちばん新しいメモの電話番号を、電話番号の欄に入れます。自分で入れた電話番号は変えません（欄が空か、前に自動で入れた番号のときだけ入れます）。相手先と電話番号は、オートコンプリートでも補います（3.5）。

## 7.4 処理と確認者

メモを処理したら、処理の欄で「処理済み」「確認済み」などを選びます。確認者が空なら、この PC の人の所員名を入れます。処理を入れたメモは、一覧で灰色の字になり、入力欄の番号の右に処理を出します。

## 7.5 メールで知らせる

宛先の所員に、メモをメールで知らせます。

1. 宛先を選びます（宛先の所員のメールアドレスを、事務所の設定の「所員」に入れておきます）。
2. 編集モードで［メールを送る…］を押します。直した値があれば、先に書き込みます。
3. 宛先とメールアドレスを確かめて［OK］を押すと、ふだん使うメールソフトが、宛先・件名（電話メモ）・本文（番号・日付・時間・相手先・電話・宛先・用件・対応・内容・入力者）を入れた状態で開きます。
4. メールソフトで内容を確かめてから、送信を押します。VA Call は、メールを送りません。
5. メモのメール送信日時に、［メールを送る…］で［OK］を押した日時を書きます。

- 本文が長いときは、本文をクリップボードに写し、メールソフトには「（本文を貼り付けてください）」と入れて開きます。メールの本文に貼り付けてから送信してください。
- すでに送ったメモでは、もう一度送るかを尋ねます。
- メール送信日時は、メールソフトで送信したかどうかではなく、メールソフトを開いた日時です。

## 7.6 メモを消す

編集モードでメモを選び、リボンの［消す］を押します。確かめてから消します。消したメモは元に戻せません。

# 第8章 暗号化した仮想ドライブ・同期フォルダで使う

## 8.1 暗号化した仮想ドライブの中で使う

共有フォルダを、暗号化した仮想ドライブ（Cryptomator など）の中に置いても使えます。共有データは、その中に置いた JSON のファイルで、ツールは、ふつうのフォルダのファイルとして読み書きします。ツールそのものには、データを暗号化する機能はありません。

暗号化した仮想ドライブや同期フォルダでは、ほかの PC の書き込みが見えるまでに遅れがあり、ファイルの日時がずれることもあります。そのため、次のように作っています。

- 書き込みの競合は、ファイルの日時ではなく、共有データの中に書いた値（書き込みごとの番号）で確かめます。
- 「編集中」の印を置いた直後に、ほかの人の印がないかを確かめ直します。ほぼ同時に2人が編集を始めたときは、退きます（「ほぼ同時に編集を始めました」と出ます）。
- 同期のソフトが作った競合の写しを見つけたら、知らせて止めます（10.1）。
- OS のファイルのロックや、ファイルの変化の知らせには頼りません。

暗号化した仮想ドライブは、Windows からはネットワークドライブとして見え、ごみ箱がありません。そのため、読込フォルダが仮想ドライブの中にあるときは、VA Filing・VA Receipt の［消す］はファイルを消さずに知らせます。エクスプローラーで消してから、［ファイルを読み込む］を押してください（5.7）。

## 8.2 フォルダが見つからないと止まる理由

保管先・移送待ち・バックアップなどの基点のフォルダが見つからないときは、新しく作らずに、「…が見つかりません。暗号化した仮想ドライブを使っている場合は、開いているか（ロックを解除しているか）を確かめてください。」と知らせて止まります。ツールが作るのは、基点の下のフォルダ（移送待ちの中の、フォルダ規則の場所など）だけです。

暗号化した仮想ドライブを、ドライブ文字ではなく、既存のフォルダに割り当てている場合、仮想ドライブを閉じている間、割り当て先はふつうのフォルダです。そこにフォルダを作ってファイルを置くと、書類が暗号化されないまま保存されてしまいます。また、共有フォルダの接続が切れているときや、設定の場所を誤っているときに、思わぬ場所にフォルダを作ることも防げます。

止まったときは、仮想ドライブが開いているか、共有フォルダにつながっているか、設定の場所が正しいかを確かめてください。

## 8.3 同期フォルダ（OneDrive・SharePoint）で使うときの注意

- ほかの PC の変更が届くまでに、数秒から数分かかることがあります。続けて別の人が編集を始めるときは、前の人の変更が届いてから［編集を始める］を押してください。
- 同期の遅れの間に、2人がほぼ同時に編集を始めると、2人とも編集モードに入ることがあります。その場合も、後から書き込んだ人は「共有データが、読み込んだ後に…更新されています」と出て止まり、共有データが黙って上書きされることはありません。［最新を読み込む］を押してから、直し直してください。
- 2台の PC で同時に書き込まれると、同期のソフトが競合の写しを作ることがあります。見つけたら知らせるので、10.1 のとおりに直してください。
- VA Filing・VA Receipt のプレビューや、VA Case の ZIP の作成で、手元にない（クラウドだけの）ファイルを読むと、ダウンロードが始まり、時間がかかります。

## 8.4 終了事件の置き場所（保管庫）

終了した事件は、ふだん開かない場所（保管庫）に置くと、PC を乗っ取られたときに持ち出される量を減らせます。保管庫には、次のような場所が使えます。

- ふだん開かない、暗号化した仮想ドライブ（自動では開かない設定にしたもの）
- ふだん取り外しておく外付けのディスク
- クラウド・NAS の、ふだんつながない場所

VA Case は、終了処理で、日常の共有フォルダの中の「移送待ち」に、保管庫と同じフォルダ構成（フォルダ規則）で ZIP を置くまでを行います。保管庫には一切触れません。保管庫を常に開いておく使い方を、ツールの側から後押ししないためです。

**保管庫へ移す**

1. 保管庫を開きます（接続します）。
2. 移送待ちの中身を、フォルダの構成のまま、保管庫に重ねて移します（エクスプローラーで行います）。
3. 移し終えたら、保管庫を閉じます（取り外します）。

**取り外せる媒体を使うときの注意**

- なくしたり盗まれたりしたときに備えて、媒体そのものを暗号化してください。
- 壊れたときに備えて、2台に分けて保管してください。
- 移した後は、すぐに取り外してください。

終了した事件のデータを VA Case から開く機能はありません（4.8）。終了した事件は、保管庫を開いて、エクスプローラーで探します（そのために、フォルダ規則で、分かりやすいフォルダの構成にしておいてください）。

# 第9章 試用データ

4つのツールを、架空のデータで試せます。付属のスクリプト `scripts\make_trial_all.py` で、架空の氏名・住所・番号・ファイルだけを使った試用の場所を作ります。実データを使わずにツールを試すときや、AI を使ってツールを改造するとき（第11章）に使います。

Python を入れた PC で、ソースのフォルダの中で、次を実行します。

```
python -m pip install -r requirements.txt
python scripts\make_trial_all.py [作る場所]
```

作る場所を省くと、ソースのフォルダの中の「試験用」に作ります。すでにあれば、作り直しません（消してから実行します）。次のものを作ります。

| フォルダ | 中身 |
|---|---|
| 共有 | 4つのツールの共有データ（`VA_Case.json`・`VA_Filing.json`・`VA_Receipt.json`・`VA_Call.json`） |
| 事件 | 架空の事件のデータフォルダ |
| スキャン | VA Filing の読込フォルダ（架空のファイル。読み込む前のものを含みます） |
| 領収書スキャン | VA Receipt の読込フォルダ（架空の領収書。読み込む前のものを含みます） |
| 経理・未確認・写し・職務上請求・文献・移送待ち・保管庫・バックアップ など | 保管フォルダ・写しの置き場所・移送待ちなど |

最後に、この PC の4つのツールの設定（`%APPDATA%\VA Case`）を、試用の場所に向けるかを尋ねます。`y` を入れると向けます。

**元の設定に戻す**

試用の場所に向けたときは、前の設定を `<ツール>_試用前.json`（`case_試用前.json` など）として残します。元に戻すときは、ツールを閉じてから、`%APPDATA%\VA Case` の `case.json` などを消し、`case_試用前.json` などの名前を `case.json` などに戻します。

# 第10章 困ったとき

## 10.1 よくある知らせと対処

| 知らせ・ようす | 対処 |
|---|---|
| 「〇〇さん（PC の名前）が編集中です。閲覧だけできます。」 | その人が［編集を終える］を押すのを待ちます。その PC が止まるなどして、編集を終えないまま印が残っているときは、本人に確かめてから、知らせに出たロックファイル（`VA_Case.json.<人>@<PC>.lock` など）をエクスプローラーで消してください。自分の PC に残った印は、次に自分が［編集を始める］を押すと置き換わります |
| 「〇〇さんが、ほぼ同時に編集を始めました。自分の編集の開始を取り消しました。」 | 少し待ってから、もう一度［編集を始める］を押すか、相手と順番を決めてください |
| 「共有データが、読み込んだ後に…更新されています。書き込みを止めました。」 | ［最新を読み込む］を押してから、変更をやり直してください |
| 「編集の権利がないため、書き込めません。」 | もう一度［編集を始める］を押してください。ロックファイルが消されたときなどに出ます |
| 「共有フォルダに、共有データの「競合の写し」と思われるファイルがあります。」 | 2台以上の PC で同時に書き込まれ、同期のソフトが別のファイルとして残したものです。どちらの内容が正しいかを確かめ、要らない方を共有フォルダの外へ移してから、もう一度操作してください。閲覧はできますが、編集の開始と書き込みは止まります |
| 「共有データのファイルが見つかりません。」「共有フォルダが見つかりません。」 | 暗号化した仮想ドライブが開いているか、同期が終わっているか、共有フォルダにつながっているか、この PC の設定の場所が正しいかを確かめてください |
| 「共有データのファイルを正しく読めませんでした」 | 同期の途中の可能性があります。しばらく待ってから［最新を読み込む］を押してください。続くときは、バックアップから戻します（10.2） |
| 「共有データのテーブル「〇〇」の列が、このアプリと合いません」 | ツールの版が、事務所のほかの PC と違う可能性があります。同じ版にそろえてください |
| 「書き込んだ後の確かめで、書いた内容と一致しませんでした。」 | ほかの PC の書き込みや同期と重なった可能性があります。［最新を読み込む］を押して、内容を確かめてください |
| 「バックアップのフォルダが見つからないため、バックアップを作りませんでした。」 | バックアップのフォルダがあるか、暗号化した仮想ドライブが開いているかを確かめてください |
| 「VA Case の事件を読めませんでした。」（VA Filing） | VA Filing の「この PC の設定」の「VA Case の共有データ」の場所を確かめてください。読めない間は、事件呼名を、VA Filing の保管先からだけ選べます |
| 「…を、この PC の場所として読めません（事務所のフォルダの場所を設定してください）。」 | ほかの PC が、事務所のフォルダの場所からの相対で書いたフォルダです。この PC の設定の「事務所のフォルダの場所」を入れてください（2.6） |
| 「このファイルを移動できませんでした。ファイルが別のアプリケーションで開かれているかもしれません。」 | そのファイルを開いているソフトを閉じてから、もう一度［保管する］を押してください |
| 「書き込めなかった変更のある事件が〇件あります」（閉じるとき） | ［いいえ］を押して閉じずに、［最新を読み込む］などで書き込めなかったわけを確かめてください。［はい］を押すと、書き込まずに閉じます |
| 画面が出るまで時間がかかる | 起動のたびに実行ファイルを展開するためです。しばらく待ってください |

## 10.2 共有データをバックアップから戻す

共有データが壊れて読めないときや、誤って多くの記録を消したときは、日次バックアップ（3.9）から戻せます。バックアップのファイルは、その日の最初に読み込んだときの共有データと同じ中身です。

1. 事務所の人みなに、そのツールを閉じてもらいます。
2. 共有フォルダの共有データ（`VA_Case.json` など）を、共有フォルダの外へ移します（念のため、消さずに残します）。
3. バックアップのフォルダから、戻したい日のファイル（`yyyymmdd_VA_Case.json` など）を共有フォルダへ写し、名前を `VA_Case.json` などに改めます。
4. ツールを起動して、内容を確かめます。

バックアップの日より後に入れた記録は、戻した共有データには入っていません。入れ直してください。

# 第11章 AI を使ってツールを改造するとき

VA Caseシリーズはソースコードを公開しており（第12章）、事務所独自の機能を、AI（プログラムを書くのを手伝う AI）を使って足すこともできます。その場合は、次の手順で、**AI が実データ（依頼者・事件の情報）に届かない場所で作業させてください。**

## 11.1 なぜ注意が必要か

AI が読んだファイルや画面は、AI の会社のサーバーに送られます。依頼者の情報を AI に読ませると、守秘義務の点で問題になり得ます。AI は作業の途中で、思わぬファイルを開くことがあります。そのため、「気をつけて使う」だけでは防げません。AI が実データに届かない場所で作業させてください。

依頼者の氏名は、共有データの中身だけでなく、データフォルダ・保管フォルダの名前や、この PC の設定ファイルに書かれた場所にも入っていることがあります。

## 11.2 手順1　AI 専用の Windows ユーザーを作る

- ［設定］→［アカウント］→［他のユーザー］で、AI の作業に使うユーザーを作ります。管理者にはせず、標準ユーザーにします。
- このユーザーでは、事務所の OneDrive・SharePoint にサインインしません。共有フォルダ・ネットワークドライブ・暗号化した仮想ドライブにもつなぎません。
- 作ったら、このユーザーでエクスプローラーを開き、事務所の共有データの場所が見えないこと、開けないことを確かめます。見える場合は、そのフォルダのアクセス許可からこのユーザーを外してください。
- 別の PC を AI の作業に使えるなら、さらに確実です。

## 11.3 手順2　このユーザーで、ソースと試用データだけを使って作業する

- ソースは、このユーザーで新しく手に入れます（GitHub の VBA-Assets/VA_CASE から取ります）。ふだんのユーザーのフォルダから写さないでください。
- 試すデータは、付属のスクリプト（`scripts\make_trial_all.py`。第9章）で作る架空のデータを使います。実際の共有データ・バックアップ・CSV・事件のフォルダは使いません。
- この PC の設定ファイル（`%APPDATA%\VA Case` の `case.json` など）は、このユーザーで新しく作られたものを使います。ふだんのユーザーの設定ファイルを写さないでください（共有データやフォルダの場所など、フォルダの名前に依頼者の名前が入っていることがあります）。
- 実データの中身を、AI に貼り付けたり、画面の写しで見せたりしないでください。
- 不具合を AI に相談するときは、ツールの［ヘルプ］→［診断情報をコピー］（3.10）を使います。診断情報には、件数やエラーの場所だけが入り、氏名などの中身は入りません。

## 11.4 手順3　実データでの確認と入れ替えは、ふだんのユーザーで人が行う

- 改造してできた exe（またはソースから動かすもの）を、ふだんのユーザーに移します。
- 共有データのバックアップを取ってから、まず実データの写しを置いた試験用のフォルダで試します。問題がなければ、ふだんの共有データで使い始めます。
- 共有データの形を変える改造をしたときは、事務所のすべての PC で、同じ版を使ってください（版の違うツールが同じ共有データを読むと、「列が、このアプリと合いません」と出ることがあります）。
