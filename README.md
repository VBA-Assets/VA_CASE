# VA Caseシリーズ — 事件の情報・ファイル・領収書・電話メモを、事務所の共有フォルダで管理するツール

VA Caseシリーズは、小規模な法律事務所が、事件の情報・保管するファイル・領収書など・電話の記録を、
事務所の共有フォルダ（SharePoint・OneDrive の同期フォルダを含む）だけで、何人かで共有・管理するための、
Windows 用の無料ツールです。サーバーやクラウドのサービスは使いません。

| ツール | 実行ファイル | できること |
|---|---|---|
| VA Case | `VA_Case.exe` | 事件の情報（依頼者・相手方・裁判所・担当など）の管理。事件メモ・期日請書・送付書の PDF の作成。終了した事件のデータフォルダの ZIP |
| VA Filing | `VA_Filing.exe` | スキャンや受信 FAX などのファイルを、名前を付けて事件のフォルダへ保管する。担当者へのショートカット・写しの作成 |
| VA Receipt | `VA_Receipt.exe` | 領収書などのファイルを、日付・相手先・金額の名前を付けて、種別ごとのフォルダへ保管する |
| VA Call | `VA_Call.exe` | 電話のメモの記録と、担当者へのメール（既定のメールソフトで送る） |

4つは別々の実行ファイルで、必要なものだけを使えます。VA Filing は、VA Case の事件の一覧を読んで、
保管先の事件を選べます。

## 特徴

- **共有フォルダだけで動く**：共有データは、ツールごとに1つの JSON のファイルです。書き込むときは、
  一時ファイルに書いてから置き換え、書き込む直前に、ほかの人の書き込みとの競合を確かめます。
- **編集は1人ずつ**：ツールごとに、編集モードにできるのは1人だけで、ほかの人は閲覧になります。
- **外部と通信しない**：プログラムはインターネットにつながりません。事件の情報は、事務所のフォルダの外へ出ません。
- **暗号化した仮想ドライブの中でも使える**：共有フォルダを、Cryptomator などで暗号化した仮想ドライブの中に
  置いても使えるよう、同期・暗号化による遅れを見込んで作っています。

## 動作環境

- Windows 10 / 11（64bit）。インストーラー（VA Caseシリーズ（統合版））で入れるか、配布物の exe を
  そのまま起動します。
- インターネット接続は不要です。
- Mac では、ソースから動かす場合に限り使えます（動作は保証しません。ショートカットは作らず、写しだけを作ります）。

## ソースから動かす

```
python -m pip install -r requirements.txt
python main_case.py      # VA Case
python main_filing.py    # VA Filing
python main_receipt.py   # VA Receipt
python main_call.py      # VA Call
```

試用の架空のデータ（4つのツールの共有データと、架空の事件・ファイル・領収書）は、次で作れます。

```
python scripts\make_trial_all.py [作る場所]
```

## 実行ファイルを作る

```
python -m PyInstaller va_case.spec --noconfirm
```

`dist\` に4つの exe ができます。
